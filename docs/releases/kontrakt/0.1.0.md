# budstikka-kontrakt 0.1.0

## Innhold

Første pilotutgivelse av produsentfasaden:

- `brukervarselCreate` og `brukervarselInactivate`
- `dineSykmeldteVarselCreate` og `dineSykmeldteVarselInactivate`
- `brevCreate`
- `microfrontendEnable` og `microfrontendDisable`
- `EncodedDispatch` med topic, mottakerbasert Kafka-nøkkel, JSON-payload og `eventId`-header

## Kompatibilitet

Artefakten krever minst Kotlin 2.3 og Java 21. Produsenten eier selv `kafka-clients`; kontrakten
tar bare med nødvendig Kotlin-serialisering transitivt. Se
[producerguiden](https://github.com/navikt/syfo-budstikka/blob/main/docs/sende-varsler.md) for
påkrevd Kafka-tilgang.

Dette er første versjon. Det finnes ingen deprecations, breaking changes eller migrering fra en
tidligere kontraktversjon.

## Ikke støttet

`DittSykefravaer` og `Arbeidsgivervarsel` er ikke med på fasaden fordi Budstikka mangler
runtime-støtte. `0.1.0` er en pilot og gir ikke esyfovarsel-paritet. `1.0.0` avventer
pilot- og paritetsgjennomgang.
