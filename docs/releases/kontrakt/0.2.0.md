# budstikka-kontrakt 0.2.0

## Innhold

Andre pilotutgivelse av produsentfasaden. Denne versjonen legger til `Budstikka.arbeidsgivervarselCreate(...)` for `Arbeidsgivervarsel.NarmesteLeder` og `Arbeidsgivervarsel.AltinnResource`, med valgfri `visibleUntil`.

Wireformatet er uendret. Kafka-topic, `eventId`-header, standardverdier og `orgnummer` som partisjonsnøkkel er det samme som før.

## Kompatibilitet

Artefakten krever fortsatt minst Kotlin 2.3 og Java 21. Endringen er additiv mot `0.1.0` og innebærer ingen breaking endring i producer-API-et. Produsenter kan oppgradere når de trenger den nye fasaden.

## Ikke støttet

Dette legger bare til create-støtte for `Arbeidsgivervarsel`. `0.2.0` gir fortsatt ikke full esyfovarsel-paritet, og andre operasjoner er fortsatt ikke støttet.
