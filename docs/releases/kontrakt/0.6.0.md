# budstikka-kontrakt 0.6.0

## Innhold

`Oppgavetype` har fått tre nye verdier for Dine Sykmeldte: `DIALOGMOTE_ENDRING`,
`DIALOGMOTE_AVLYSNING` og `DIALOGMOTE_REFERAT`. Dialogmøteprodusenter kan dermed skille
endring, avlysning og referat fra innkalling. `DIALOGMOTE_INNKALLING` er en grupperingsverdi
nedstrøms og skal ikke brukes som stand-in for de andre.

Wire-verdiene er identiske med navnene og samsvarer med verdiene Dine Sykmeldte allerede
støtter. Eksisterende wire-verdier er uendret.

## Migrering fra 0.5.0

Endringen er additiv. Ingen eksisterende kall må endres.

## Wire- og utrullingskompatibilitet

En eldre Budstikka kan ikke dekode de nye verdiene. Produsenter skal derfor først ta dem i bruk
etter at Budstikka med denne kontraktversjonen er fullt utrullet. Meldinger med eksisterende
verdier leses som før.
