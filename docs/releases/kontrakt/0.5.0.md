# budstikka-kontrakt 0.5.0

## Innhold

`Budstikka.dittSykefravaerCreate` og `Budstikka.dittSykefravaerInactivate` er nye,
additive funksjoner for Ditt Sykefravær. Opprettelse krever `messageType`, en stabil
analytics-synlig kategori som aldri skal inneholde personopplysninger.

Budstikka leverer opprettelser som Flex-kontraktens faste `INFO`-variant med
`lukkbar = true`. Lukking publiseres med samme stabile `reference` som Kafka-nøkkel og
en leverings-timestamp.

## Migrering fra 0.4.0

Produsenten lagrer en stabil, ikke-personidentifiserende `reference` sammen med egen
forretningshendelse og bruker samme `reference` og `sykmeldt` ved
`dittSykefravaerInactivate`. Ikke bruk rå wire-typer eller publiser direkte på Flex-topic-et.

Budstikkas API er additivt. Flex eier fortsatt den eksisterende nedstrøms
Kafka-kontrakten og topic-ACL-en; en produsentmigrering kan starte først når
`syfo-budstikka` har fått write-ACL fra topic-eieren.
